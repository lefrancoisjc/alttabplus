Windows 10 / 11

Alt+Tab that treats a Snap Group as one thing.

Native Alt+Tab lists the group and every window inside it. AltTabPlus collapses the layout into a single tile, with live previews, then gets out of the way.

One tile per group

Snapped windows stay a layout. Release Alt to bring the whole group forward without breaking the snap.

Expand when you need one

Click, Space, or ↓ opens the group. Pick a single window. Esc goes back.

Type to filter

Start typing. Delete or middle-click closes a window. Alt+` cycles the same app.

Hot corners

macOS-style corners: Task View, this switcher, desktop, next or previous virtual desktop. Off during exclusive fullscreen games.

Your scope

Current monitor only, hidden windows, other desktops, ignore list. Settings stay in LocalAppData.

English or French

The app follows the Windows display language. No account, no telemetry, no network.
